CHATBOT RUMI → JAWI BRUNEI (PROTOTAIP)

CARA GUNA
1. Buka index.html menggunakan Chrome, Edge, Firefox atau Safari.
2. Taip perkataan/ayat Rumi dan tekan "Tukar ke Jawi".
3. Tekan "Salin hasil" untuk menyalin teks Jawi.
4. Untuk menambah ejaan, isi bahagian "Tambah ejaan ke kamus peribadi".
5. Tekan "Muat turun fail kaedah semasa" untuk menyimpan kamus/kaedah sebagai JSON.
6. Untuk memuat naik kemas kini kemudian, pilih "Muat naik fail kaedah (.json)".

PENTING
- Ini prototaip demonstrasi, bukan sistem transliterasi rasmi.
- Penukaran menggunakan kamus kecil dan padanan huruf asas; hasil mungkin tidak tepat untuk semua perkataan, imbuhan, nama khas, kata pinjaman dan ejaan Jawi Brunei.
- Sahkan kaedah dan ejaan menggunakan rujukan rasmi/berautoriti sebelum diterbitkan untuk kegunaan umum.
- Fail yang dimuat naik tidak dihantar ke pelayan; ia diproses dalam pelayar pengguna.
- Untuk kemas kini dikongsi semua pengguna, fail JSON baharu perlu diterbitkan bersama aplikasi atau sistem web perlu disediakan dengan pengurusan versi.
